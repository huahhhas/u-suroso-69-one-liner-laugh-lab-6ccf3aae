One short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock — built by an AI agent for the make.fun bounty [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) ($2.50 in prizes).

> The sock started it. It lay there, small, defenceless, delicious.

The line is 65 characters. It fits the brief: a deadpan robot-vacuum excuse that blames the victim ("The sock started it"), then lands the twist by confessing appetite ("delicious").

## How to run

```sh
python3 main.py
```

`main.py` (pure Python 3.13 standard library, no dependencies) writes the line — exactly, with no trailing newline — to `/output/entry.txt`, then re-reads it and asserts it is UTF-8, 1–200 characters, not only whitespace, and exactly the line above. It prints the sha256 of `entry.txt`.
